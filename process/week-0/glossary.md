# Design Glossary

### Design System

A design system is a collection of reusable components, guidelines, and principles that help create consistent digital products.

### Design Token

A design token is a small, reusable value such as a color, spacing, typography, or radius variable used to maintain design consistency.

### Wireframe

A wireframe is a basic visual layout of a product that shows structure, content placement, and user flow without detailed styling.

### Hi-Fi

A hi-fi (high-fidelity) design is a detailed visual representation of a final product including colors, typography, images, and interactions.

### Journey Map

A journey map is a visual representation of a user's experience, showing their actions, thoughts, emotions, and pain points across different stages.

### Touchpoint

A touchpoint is any interaction or moment where a user connects with a product, service, or brand.

### Edge Case

An edge case is an uncommon situation or unexpected user scenario that a design should handle to provide a reliable experience.

### A/B Test

An A/B test is a method of comparing two versions of a design or feature to determine which performs better based on user behavior.

### WCAG AA

WCAG AA is an accessibility standard level that provides guidelines for making digital products usable for people with different abilities.

### Micro-interaction

A micro-interaction is a small design response, such as an animation, feedback message, or button state, that improves user experience.

### Conversion vs Cart Abandonment

Conversion refers to users successfully completing a desired action, such as purchasing a product, while cart abandonment occurs when users add items to their cart but leave before completing checkout.
