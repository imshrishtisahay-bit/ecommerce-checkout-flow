This week, I faced several challenges while building my UI design system. One of the main difficulties was selecting an appropriate color palette for the interface. Through research and experimentation, I learned how colors are chosen based on brand identity, accessibility, visual hierarchy, and user comfort to create a balanced and eye-friendly experience. I also explored the structure of a tokens.jsons file, understood its syntax, learned how it is managed in VS Code, and practiced uploading it to GitHub. Additionally, I strengthened my understanding of basic HTML and CSS concepts. I also found it challenging to create the main text field component with its four variants, as I needed to understand the purpose of each variant. Similarly, while creating the buttons component, I learned how different variants and interaction states contribute to a consistent, reusable, and user-friendly interface.
